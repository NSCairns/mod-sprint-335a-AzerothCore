# mod-sprint-335a-AzerothCore
A module for AzerothCore that adds Stamina, a sprint key and basic sprint bar, to be compiled with AzeorthCore as a Module

Vibe-Coded as I do not know C or much LUA use at own "risk?" I guess, idk I use it for singleplayer

Sprint is a modifier, so it stacks on top of speed, hopefully on mounts? havent tested idk it works.

The conf file can change speedmultiplier and maxstamina.

Installation Instructions:

Download zip and extract as mod-sprint directory inside of the module directory in Azerothcore/Modules

Compile AzerothCore as usual

Move ModSprintUI folder to Interfaces/Addons in the 3.3.5a wrath client
